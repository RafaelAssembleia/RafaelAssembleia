## 🪐 Featured projects

### 💳 SRM Credit Engine

**Full-stack financial receivables management and pricing application.**

- **Backend:** Java 21, Spring Boot, Spring Data JPA, PostgreSQL, Flyway.
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS.
- Present-value and discount calculations using `BigDecimal`.
- Receivables management, BRL/USD conversion, settlement operations, and operation history.
- Idempotent settlement flows, automated tests with JUnit and Mockito, and Docker-based setup.

> 🔗 **Repository:** https://github.com/RafaelAssembleia/SRM-Asset-Credit-Engine.

- Layered design with Controller, Service, Repository, and Entity responsibilities.
- Focus on object-oriented programming, validations, and maintainable code.
